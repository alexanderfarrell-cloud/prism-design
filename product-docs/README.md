# Product Docs — Lista Payroll Design

This folder is the **PM source of truth** for Prism Construction Payroll — all finalized product requirements, feature definitions, user journey maps, and supporting research live here.

This content feeds directly into the shared `lista-payroll-design` repository, making it available to PMs, Designers, and Engineering Leads in a single place.

---

## Folder Structure

| Folder | Contents | Owner |
|--------|----------|-------|
| `prds/` | Finalized Product Requirements Documents (one per module) | PM |
| `features/` | Feature lists and epic breakdowns per functional area | PM |
| `user-journey-maps/` | Persona-based and capability-based journey maps | PM |
| `backlog/` | Grooming outputs, dev team briefings, story prep docs | PM |
| `research/` | Supporting research: role definitions, rate logic, pay schedule logic | PM / Shared |
| `best-practices/` | Workflow guides, grooming playbook, Cursor setup guides | PM |

**Milestone anchor:** [`Milestone_Statements_of_Scope.md`](./Milestone_Statements_of_Scope.md) — start here for Alpha / Beta / GA scope definition.

## Conventions

- **Drafts** live in personal workspaces until ready. Only finalized artifacts belong here.
- **Naming:** `{Module}_PRD.md` for PRDs; `{Module} Features.md` for feature lists.
- **No Figma-only links.** Export or annotate for offline reference.
- When a document is updated, update it here — ADO is the source of truth for individual work items, this folder is the source of truth for requirements and design intent.
